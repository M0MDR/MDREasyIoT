This is a collection of scripts to work with EasyIoT.

It may be helpful for people who try to reverse engineer the upload of data into an EasyIoT server.

EasyIot's server software is located here: https://iot-playground.com/

I am unable to run EasyIoT on my webspace so I am currently working on a LAMP solution which I aim to publish here once it has reached a useful stage.
